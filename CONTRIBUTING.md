# Contributing

Thanks for wanting to improve the path tracer. Contributions are welcome, but this project
has specific terms. Read these before you open a pull request, because submitting one means
you agree to them.

## Terms for contributing

1. You may modify and improve the project and submit those improvements here (for example,
   by pull request).

2. By submitting a contribution, you agree to transfer ownership of the submitted code to
   the official project under cosypa123, under legally valid and explicitly agreed terms.
   If you are not willing to transfer ownership, do not submit the contribution.

3. You will be credited in the project's description or a designated credits section for
   your contribution.

4. Your contribution must not replace, remove, or obscure the original authorship credit to
   cosypa123.

5. Contributing does not grant you permission to incorporate the path tracer into a separate
   game. Game integration always requires separate prior written permission from cosypa123,
   no matter how much you contributed or modified. See the LICENSE for details.

## How to contribute

1. Fork the repository.

2. Make your change. Keep it focused: one improvement or fix per pull request is easier to
   review than a pile of unrelated changes.

3. Test it in Roblox Studio first. This is a renderer, so "it works" means you actually ran
   it and looked at the output, not just that it compiles. Note what you tested on (map,
   settings, Studio vs client) in the pull request.

4. Open a pull request describing what you changed and why.

## What makes a good contribution

- Performance improvements that do not sacrifice quality, with before/after numbers
  (measure in the Roblox client, not Studio: Studio is much slower and not representative).
- Visual quality improvements, with screenshots showing the difference.
- Bug fixes.
- New materials, new sampling strategies, cleaner code.

If you are planning something large, reach out first (Discord: cosypa123) so you do not
spend a week on something that will not be merged.
